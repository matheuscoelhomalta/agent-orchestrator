# Code of conduct

Treat contributors and users with respect. Discuss ideas and evidence, give constructive feedback, and welcome people with different backgrounds and levels of experience.

Harassment, threats, discrimination, sexualized conduct, deliberate disruption, and publishing another person's private information are not acceptable in project issues, pull requests, or other project spaces.

Maintainers may edit or remove inappropriate contributions, lock discussions, or restrict participation. Responses should be proportionate to the behavior and its impact.

Report abusive public content through GitHub's **Report content** control or [GitHub Support](https://support.github.com/contact/report-abuse). For a project moderation request that can be discussed publicly, open an issue identifying the relevant public content. Do not disclose personal information or sensitive allegations in a public issue. Security vulnerabilities have a separate [private reporting process](SECURITY.md).
